# BMD_vascular_calcification_Tsimane

The current repository contains the code to produce results for the paper _Bone demineralization accompanies vascular mineralization in physically active adults with few cardiometabolic risk factors_, by Jonathan Stieglitz et al., and a data simulation developed for code testing only. 

Note that while the makefile will run on simulated data only and produce (fake) plots that match those presented in the main text, the SI will not fully compile on simulated data only, as the descriptive sections of it requires original data. However, the simulated data allow to test the main results as well aqs the single chunks relative to the models' results in the SI.
